Secure File Storage System

A C++17 desktop application for encrypting and decrypting files and text, with role-based access control and a custom file-index engine.

C++17 SFML 2.6.x Windows 10+

About

Secure File Storage System is a console + GUI application that demonstrates a complete mini secure-storage workflow: create, view, delete, and search files whose contents are encrypted at rest. It combines XOR-based encryption, djb2-hashed credential storage, and role-based authentication (ADMIN / USER / GUEST) with a custom singly-linked-list index to track and traverse stored files.

Built entirely in C++17 with an SFML graphical interface, the project is designed as an educational exploration of cryptography fundamentals, access control, and hand-rolled data structures rather than a production-grade security tool.

Features

  • Encrypt / decrypt on demandFiles are XOR-encrypted with hex encoding before being written to disk, and decrypted transparently on read.
  • Role-based access controlADMIN, USER, and GUEST roles enforce distinct permissions for creating, viewing, deleting, and registering files or users.
  • Linked-list file indexA custom singly-linked list tracks file metadata in memory and supports traversal-based search.
  • SFML graphical interfaceDark-themed login screen, file browser, and dialogs built with SFML.
  • Persistent encrypted storageEncrypted files and the index survive across application restarts in secure_storage/.
  • Hashed credential storePasswords are verified against a djb2-hashed store rather than kept in plaintext.

A Note on Security

Educational project. XOR encryption is not secure against modern attackers and is used here to demonstrate concepts, not to protect real data. The README recommends AES-GCM or libsodium, Argon2/bcrypt/scrypt password hashing, and AEAD integrity checks for any real-world hardening.
